# JEE Tracker — Personal Preparation Dashboard

A zero-dependency, mobile-friendly JEE preparation tracker.

## Included
- Physics, Chemistry, Maths chapter tracker
- Status: Not Started / In Progress / Done / Revised / Mastered
- Daily study-hours log
- PYQ tracker with accuracy
- Mock-test analytics
- Revision queue
- Backlog manager
- Mistake notebook
- Daily targets
- Local browser storage
- JSON backup export/import
- Dark/light mode
- Responsive mobile layout

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. Start using the tracker.
4. Your data is saved in the browser.

## Put it online with GitHub Pages
1. Create a GitHub account if you don't have one.
2. Create a new repository, e.g. `jee-tracker`.
3. Upload `index.html`, `style.css`, and `app.js` to the repository root.
4. Open repository Settings → Pages.
5. Under "Build and deployment", select "Deploy from a branch".
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide your Pages URL.

## Important
This app is client-side only. Data is stored in localStorage in the browser/device. Export a JSON backup regularly if the data matters.

The included chapter list is a practical JEE tracker list and is editable. Check the official NTA/JEE syllabus for the exact exam-year syllabus before using it as an official syllabus checklist.
