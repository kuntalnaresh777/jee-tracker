# JEE Tracker — Preparation OS

Personal JEE Main + Advanced + CBSE Boards tracker.

## Features
- First-open onboarding: name, exam, attempt, target and optional exam dates
- Personalized dashboard and local browser storage
- JEE Main / Advanced / CBSE countdowns
- Animated progress ring and 7-day study timeline
- Today's planner with checkboxes for Class, Notes, HW, PYQ, Revision, Mock Test
- Focus timer
- JEE syllabus tracker with status and priority selectors
- Study log and weekly analytics
- PYQ tracker and mock-test analytics
- Spaced revision queue
- Mistake book
- CBSE Boards hub with checklist and subject progress
- Import/export backup
- Dark/light mode
- Responsive mobile layout
- User-supplied portrait used as the app logo/favicon
- Footer: All rights reserved © Naresh Kuntal

No backend is required. Data is saved in the browser's localStorage.
