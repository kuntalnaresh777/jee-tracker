# JEE Tracker — Naresh Kuntal PRO

A zero-dependency, mobile-friendly JEE + CBSE preparation dashboard that runs directly on GitHub Pages.

## Included
- Personalized first-run setup: name, exam, attempt, target and exam dates
- JEE Main / Advanced / CBSE countdowns
- Subject-wise daily checklist: Class Attend, Notes, HW/DPP, PYQ, Revision, Test
- JEE syllabus tracker with status + priority
- Study-hour log, PYQ tracker, mock tests, revision queue and mistake book
- CBSE Boards hub
- Focus timer
- Local browser save + JSON backup/import
- **One-click A4 Weekly Progress Report** (Monday–Sunday)
- **One-click A4 Daily Task Sheet** with ready-to-print checklist, task list, time plan, Top 3 priorities and end-of-day review
- Printable reports use the app logo and `All rights reserved © Naresh Kuntal`

## GitHub Pages
1. Upload/replace `index.html`, `style.css`, `app.js`, `logo.png`, and `README.md` in your repository.
2. Commit the changes.
3. Open **Settings → Pages** and make sure the source is **Deploy from a branch → main → /(root)**.
4. Wait for GitHub Pages to finish deploying, then refresh your Pages URL.

## Printing
- Dashboard → **One-click Weekly Progress Report** for the weekly A4 report.
- Dashboard/top bar/Planner → **Print Daily Task Sheet** for a fresh daily desk sheet.
- In the browser print dialog, choose **A4** and print or **Save as PDF**.
