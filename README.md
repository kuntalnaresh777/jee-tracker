# JEE Tracker — Naresh Kuntal PRO v2

A local-first JEE + CBSE preparation dashboard.

## What's new in v2
- Larger, more readable fonts
- New profile/logo image
- Automatic daily checklist for Physics, Chemistry, Maths, English and Computer Science
- Each subject has: Class Attend, Notes, HW/DPP, PYQ, Revision, Test
- No daily task creation required — just tick checkboxes
- Dashboard shows the same checklist at a glance
- Print Today's Plan / Print Progress report (A4-friendly)
- JSON backup/export remains available
- Responsive mobile layout

## Publish on GitHub Pages
Upload/replace `index.html`, `style.css`, `app.js`, `logo.png`, and `README.md` in your repository, commit changes, and wait for GitHub Pages to rebuild.
